# 基于 LeNet-5 的手写数字识别（MNIST）

使用 PyTorch 实现经典卷积神经网络 **LeNet-5**，在 MNIST 手写数字数据集上完成识别，
并在此基础上完成两个改进实验（卷积核减半、增加 dropout）。本项目不止"跑通"，还做了
**多种子重复实验（报告 mean±std）** 与 **反事实实验**，力求把结论建立在可靠的实验证据上。

## 目录结构

```
lenet5_mnist/
├── data.py            # MNIST 数据加载与预处理（含数据下载方案、小训练集子集）
├── models.py          # 三个网络变体：原版 / 卷积核减半 / 带 dropout
├── engine.py          # 通用训练、评估、绘图工具
├── main.py            # 主入口：多种子主实验 + 反事实实验 + 汇总
├── requirements.txt
├── data/              # 自动下载的 MNIST 数据集
└── results/           # 训练产物，按用途分为四个子目录（见下）
    ├── figures/       # 📊 展示用图：训练曲线、混淆矩阵、对比图、错分样例、权衡散点
    ├── reports/       # 📄 汇总表：summary.md/csv、counterfactual.md
    ├── checkpoints/   # 💾 模型权重 .pt（复现/推理用，不必查看）
    └── logs/          # 📝 原始训练历史 json、训练日志（存档用，不必查看）
```

> **看结果只需关注 `figures/` 和 `reports/` 两个目录**；`checkpoints/` 和 `logs/`
> 是存档与复现用的原始产物。

## 关于数据集下载问题

> 题目中 LeCun 官网（yann.lecun.com/exdb/mnist）提供的原始下载链接已失效。

本项目**不依赖该链接**。解决方案是使用 `torchvision.datasets.MNIST`，它会从稳定的
官方镜像（`https://ossci-datasets.s3.amazonaws.com/mnist`）自动下载数据集。
数据与 LeCun 原始 MNIST 完全一致（60000 训练 + 10000 测试）。首次运行自动下载（约 11MB）。

### 下载数据集

**方式一（推荐，零操作）**：直接运行 `python main.py`，首次运行会自动下载到 `data/` 目录，无需任何额外步骤。

**方式二（手动预先下载）**：如果想在正式训练前单独把数据准备好，运行下面的命令即可：

```bash
python -c "from torchvision import datasets; datasets.MNIST('data', train=True, download=True); datasets.MNIST('data', train=False, download=True)"
```

下载完成后 `data/MNIST/raw/` 下会出现 4 个文件（训练/测试的图像与标签）。

**离线备用方案**：从 Kaggle（`Digit Recognizer`）下载后放入 `data/MNIST/raw/`，或用 HuggingFace `datasets` 的 `mnist`。

### 关于预训练 / 初始权重

**本项目不需要下载任何预训练权重或初始权重。** 所有模型均从随机初始化开始训练，
代码中通过 `set_seed()` 固定随机种子以保证初始化可复现。`results/checkpoints/` 下的 `.pt`
文件是**训练结束后产出**的模型权重（供复现评估/推理使用），而非训练的前提条件。

## 网络结构

严格复刻 LeCun(1998) 原始 LeNet-5：输入 **32×32**（MNIST 28×28 补边 padding=2），
激活 **tanh**，池化用 **平均池化**。训练用 Adam，学习率 1e-3，交叉熵损失，batch_size=128。

| 层 | 类型 | 输出尺寸 |
|---|---|---|
| C1 | 卷积 6@5×5 | 6×28×28 |
| S2 | 平均池化 2×2 | 6×14×14 |
| C3 | 卷积 16@5×5 | 16×10×10 |
| S4 | 平均池化 2×2 | 16×5×5 |
| C5 | 卷积 120@5×5 | 120×1×1 |
| F6 | 全连接 | 84 |
| 输出 | 全连接 | 10 |

### 三个任务

- **任务1 — 原版 LeNet-5**（`LeNet5`）：参数量 61,706。
- **任务2 — 卷积核减半**（`LeNet5Half`）：卷积核 6→3、16→8、120→60，参数量降至 18,720（约原版 30%）。
- **任务3 — 增加 dropout**（`LeNet5Dropout`）：在两个池化层后及 F6 后插入 Dropout，测试 **1% / 5% / 10%** 三种丢弃率。

---

## 主实验结果（10 epoch，3 个种子的 mean±std）

| 模型 | 参数量 | 最佳测试准确率 | 训练准确率 | 过拟合差距 |
|---|---|---|---|---|
| 任务1 原版 LeNet-5 | 61,706 | **98.87% ± 0.12%** | 99.51% | 0.65% |
| 任务2 卷积核减半 | 18,720 | 98.63% ± 0.10% | 99.00% | 0.37% |
| 任务3 dropout 1% | 61,706 | 98.87% ± 0.07% | 99.44% | 0.66% |
| 任务3 dropout 5% | 61,706 | 98.81% ± 0.02% | 99.23% | 0.52% |
| 任务3 dropout 10% | 61,706 | 98.74% ± 0.10% | 98.92% | 0.26% |

**关键观察：各模型的差异（≤0.24%）与种子间的标准差（~0.1%）量级相当**，说明在完整 MNIST 上，
这些模型的测试精度差异大多落在随机波动范围内，不能简单说"谁一定比谁强"。这正是做多种子实验的意义——
避免被单次运行的偶然结果误导。

## 反事实实验：dropout 什么时候才会"反超"原版？

**动机**：在完整 MNIST 上 dropout 没有带来提升，是因为任务太简单、原版几乎不过拟合。
为验证 dropout 的正则化作用确实存在，我们**人为制造过拟合场景**：训练集砍到 **1000 张**，训练 40 epoch。

| 模型 | 测试准确率 | 训练准确率 | 过拟合差距 |
|---|---|---|---|
| 原版 LeNet-5 | 93.00% ± 0.14% | **100.00%**（完全记住训练集） | 7.00% |
| dropout 10% | 93.15% ± 0.09%（**+0.15%**） | 99.50% | 6.35% |
| dropout 20% | **93.24% ± 0.12%（+0.24%）** | 98.37% | 5.13% |

**结论非常清晰**：当模型严重过拟合时（原版训练准确率飙到 100%），
**dropout 的测试准确率反超原版，且 dropout 越大、过拟合差距越小、测试精度越高**。
这就从可控实验的角度证明了——dropout 没有在完整 MNIST 上提升精度，不是它无效，
而是那个任务根本不需要它。**dropout 的收益取决于任务是否过拟合。**

| 图 | 这是什么 | 怎么看 / 能得到什么结论 |
|---|---|---|
| `comparison.png` | 5 个模型最佳测试准确率对比柱状图（**带误差棒**） | 误差棒 = 种子间标准差。若两根柱子的误差棒重叠，说明差异不显著。本图印证"完整 MNIST 上模型差异多在噪声内"。 |
| `params_vs_accuracy.png` | 参数量(对数轴) vs 测试准确率 散点图 | 直观看"性价比"：任务2(减半)点在左侧（参数少），纵向只比原版低一点点——**用 30% 的参数换来约 99.7% 的性能**，轻量化很划算。 |
| `counterfactual.png` | 反事实实验：小训练集下 原版/dropout10%/dropout20% 的训练vs测试准确率 | 橙色(train)远高于蓝色(test)=过拟合。看蓝色柱：dropout 越大 test 越高；看橙蓝差距：dropout 越大差距越小。**这张图是"dropout 反超原版"的直接证据。** |
| `taskX_..._curves.png` | 每个模型的 loss / accuracy 随 epoch 变化曲线 | train 与 test 曲线的间距反映过拟合程度；曲线是否平滑、是否收敛反映训练是否稳定。 |
| `taskX_..._confusion.png` | 每个模型在测试集上的 10×10 混淆矩阵 | 对角线=正确，非对角线=错分。颜色最深的非对角格子就是"最容易混的数字对"（常见如 4↔9、3↔5、7↔1）。 |
| `taskX_..._misclassified.png` | 每个模型**识别错的样本**网格图，标注 `T:真实 -> P:预测` | 直接"看见"模型错在哪。很多错分样本人眼也难辨（写得潦草、歪斜），说明模型的错误大多是合理的困难样本，而非低级错误。 |

## 结论小结

1. **原版 LeNet-5** 在 MNIST 上 10 epoch 即达 **98.87%**，验证经典结构的有效性。
2. **卷积核减半**：参数量砍掉约 70%，测试精度仅降约 0.24 个百分点——原版对 MNIST 存在冗余，**轻量化性价比很高**（见权衡散点图）。
3. **Dropout**：在完整 MNIST 上未提升精度（任务本身不过拟合）；但**反事实实验证明**，一旦进入过拟合场景，dropout 能确实地缩小过拟合差距并提升测试精度，且比例越大收益越明显。**dropout 是"对症下药"的正则化手段，而非无条件涨点。**

## 局限与可改进方向（诚实说明）

- 未使用数据增强、未做学习率调度/超参搜索——目的是保持与原版 LeNet-5 的对照清晰。
- 多种子仅用 3 个，统计上够说明趋势；追求更严谨可增至 5~10 个并做显著性检验。
- 反事实实验用固定子集(1000 张)，换不同子集大小可画出"训练集规模 vs dropout 收益"的完整曲线。
